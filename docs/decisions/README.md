# Architecture Decision Records

This folder holds lightweight ADRs for meaningful technical choices made in this project. The goal is to be able to explain every decision in an interview: not just what we chose, but why, and what we traded away.

---

## Format

Each ADR is a Markdown file named `NNN-short-title.md`:

```markdown
# ADR-NNN: Title

**Date:** YYYY-MM-DD  
**Status:** Accepted | Superseded | Deprecated

## Context
What problem were we solving? What constraints applied?

## Decision
What did we choose?

## Consequences
What does this make easier? Harder? What are the trade-offs?
```
